Invoice PDF Live Preview

See the printed invoice while you edit it — no printing, no attachments

Odoo 19 · Community & Enterprise

Overview

Checking how an invoice will actually look normally means posting it, printing it, opening the generated PDF, closing it, going back to the form, fixing a line… and doing it all over again. Every round trip leaves an attachment behind and costs you a minute.

This module adds a PDF Preview button to the invoice form. The report is rendered on the fly and shown in a panel right next to the form, so you can read the real printed document — your layout, your fonts, your fiscal notes — while you are still editing the draft. Change something, hit Refresh, and the PDF updates. Nothing is ever attached to the record.

Features

  • Preview drafts — you do not have to post the invoice to see the final document.
  • Side-by-side panel — the PDF opens next to the form, not in a new tab, so the fields stay in reach.
  • One-click refresh — re-render the PDF after every change without reloading the page.
  • No stray attachments — the preview is streamed, never stored, so the chatter stays clean.
  • Your own layout — it renders the invoice report configured in your database, custom QWeb templates included.
  • Access-rights aware — a user can only preview a document they are allowed to read.
  • All document types — customer invoices, vendor bills, credit notes and receipts.

How to use it

  1. Open any invoice or bill

    Go to Accounting → Customers → Invoices and open a record — draft or posted, both work.

  2. Click "PDF Preview"

    The button sits next to Print in the top button bar. The panel slides in from the right with the rendered document.

  3. Edit and refresh

    Change a line, a payment term or the customer address, save, and press Refresh to re-render the PDF instantly.

  4. Close and post

    Close the panel when the document looks right. No attachment, no printed copy, nothing to clean up.

Technical notes

The preview is an OWL component registered in the view_widgets registry and injected into account.view_move_form, so it coexists with any other module that extends the invoice form. The PDF is served by a lightweight HTTP controller that calls _render_qweb_pdf() on the report configured for account.move — by default account.report_invoice, with an automatic fallback to any other QWeb-PDF report bound to the model.

Read access is verified with check_access('read') before rendering, so record rules and multi-company restrictions are fully respected.

Requirements. Odoo 19 (Community or Enterprise), with a working wkhtmltopdf installation — the same one Odoo already uses to print invoices. No external Python library, no configuration.

Hide Attribute Values from eCommerce Filters

Keep the shop filter panel about what customers actually pick

Odoo 19 · Community & Enterprise

Overview

Product attributes are rarely built for customers alone. Over the years they collect internal sizes, supplier references, discontinued colours, warehouse codes and the odd TEST-DO-NOT-USE — and Odoo publishes every one of them in the shop's filter panel, right next to the values that actually help someone buy.

This module adds one Visible in eCommerce toggle per attribute value. Untick it and the value disappears from the shop filters. The products carrying it keep selling exactly as before, the value still shows on the product page and in the back office, and nothing about your variants or pricing changes.

Features

  • One toggle, where you already work — a column in the attribute values list, no extra menu, no configuration screen.
  • Every filter layout — pills, colour swatches, images, dropdown, radio buttons and multi-checkbox are all covered.
  • Empty filters disappear — an attribute left with one visible value is dropped from the panel instead of showing a pointless single-option filter.
  • Search box stays honest — the "Search <attribute> (n)" counter reflects the visible values only.
  • Sales untouched — hiding a value from a filter never hides, unpublishes or blocks a product.
  • Backwards compatible — every value is visible by default, so installing the module changes nothing until you decide otherwise.

How to use it

  1. Open an attribute

    Go to Website → eCommerce → Attributes (or Sales → Configuration → Attributes) and pick the one cluttering your shop.

  2. Untick what customers should not see

    In the Attribute Values tab, switch off Visible in eCommerce on the internal or obsolete values. Save.

  3. Reload the shop

    The filter panel is rebuilt on the next page load. Nothing to publish, no cache to clear.

Technical notes

A website_visible boolean is added to product.attribute.value and a filtered website_value_ids one2many to product.attribute. The shop filter templates are inherited to iterate over that filtered set instead of value_ids — QWeb inheritance only, no Python override of the controller, so the module coexists cleanly with other eCommerce apps.

Requirements. Odoo 19 (Community or Enterprise) with website_sale installed. No external dependency.
